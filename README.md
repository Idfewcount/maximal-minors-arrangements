# Macaulay2 computations for arrangements of maximal minors

This repository contains the Macaulay2 computations accompanying the manuscript

**Marek Janasz**  
*Geometry of some determinantal arrangements*

The main computational file is

```text
maxminors_computations.m2
```

It provides exact computer-algebra calculations supporting the results on
logarithmic derivations and freeness of determinantal arrangements discussed
in the paper.

## Requirements

The computations were tested with

```text
Macaulay2 1.22
```

All calculations are exact and are performed over the rational field `QQ`.
No additional Macaulay2 packages are required.

Macaulay2 is available from

https://macaulay2.com/

## Running the computations

From a terminal, run

```bash
M2 --script maxminors_computations.m2
```

The script prints the relevant computational results directly to standard
output.

For example, the output can be saved to a file by

```bash
M2 --script maxminors_computations.m2 > output.txt
```

Some of the computations, especially those involving logarithmic derivation
modules in larger polynomial rings, may require more time and memory.

## Mathematical setting

Let

$$
M=(x_{rk})
$$

be the generic $m\times n$ matrix with $m<n$, and let $\Delta_I$
denote its maximal minors. The determinantal arrangement considered in the
paper is the divisor

$$
D_{m,n}=V(f_{m,n}),
\qquad
f_{m,n}=\prod_{|I|=m}\Delta_I.
$$

A central object in the computations is the module of logarithmic
derivations

$$
\mathrm{Der}(-\log f).
$$

If

$$
f=f_1\cdots f_s
$$

is a product of pairwise non-associate irreducible factors, the script
computes this module from the system

$$
\theta(f_i)\in (f_i),
\qquad i=1,\ldots,s.
$$

The function

```macaulay2
logDer
```

implements this construction for homogeneous factors and returns
$\mathrm{Der}(-\log f)$ as a graded submodule of a free module.

The function

```macaulay2
logDerUngraded
```

is an ungraded version used for one of the families considered in the paper.

## Structure of the script

The script is divided into the following parts.

### Part 1 — Known free cases

As consistency checks, the script computes logarithmic derivation modules for

- $D_{2,n}$, for $3\le n\le 7$,
- $D_{3,4}$.

These are known free cases.

### Part 2 — The 9-variable certificate for $D_{3,5}$

This part works in the rank-two chart

$$
N=
\begin{pmatrix}
1&0&a_3&a_4&a_5\\
0&1&b_3&b_4&b_5\\
0&0&c_3&c_4&c_5
\end{pmatrix}.
$$

It computes the logarithmic derivation module associated with the ten
$3\times3$ minors of $N$.

The calculation produces the minimal graded resolution

$$
0\longrightarrow S(-7)
\longrightarrow S(-1)^7\oplus S(-6)^3
\longrightarrow
\mathrm{Der}(-\log f'_{3,5})
\longrightarrow0.
$$

It also computes the radical of the relevant Fitting ideal and obtains

$$
(c_3,c_4,c_5),
$$

which identifies the non-free locus in this chart.

This is the computational certificate used in the proof of the
non-freeness of $D_{3,5}$.

### Part 3 — The logarithmic derivations of $D_{3,5}$

This is the main 15-variable computation.

The script computes

$$
\mathrm{Der}(-\log D_{3,5})
$$

and verifies that it has 18 minimal generators:

- 13 generators of degree $1$,
- 5 generators of degree $10$.

It computes the minimal graded free resolution

$$
0\longrightarrow R(-11)^3
\longrightarrow
R(-1)^{13}\oplus R(-10)^5
\longrightarrow
\mathrm{Der}(-\log D_{3,5})
\longrightarrow0.
$$

The script also constructs the logarithmic vector fields
$\psi_{i\to k}$ and their signed versions
$\widetilde{\psi}_{i\to k}$, and verifies computationally that

- all $\psi_{i\to k}$ are logarithmic,
- none of them belongs to the submodule generated by the linear fields,
- for fixed $k$, the fields
  $\widetilde{\psi}_{i\to k}$ are congruent modulo the linear
  logarithmic fields,
- the linear fields together with five representatives
  $\Phi_1,\ldots,\Phi_5$ generate the complete logarithmic derivation
  module,
- the three expected degree-11 syzygies generate the syzygy module.

Several different choices of the representatives $\Phi_k$ are checked.

### Part 3b — Multigraded computation

The ring is equipped with the
$\mathbb Z^3\times\mathbb Z^5$-grading corresponding to row and column
degrees.

The script computes the multidegrees of the five nonlinear generators and
of the three syzygies. In particular,

```math
\deg\Phi_k
=
\big((3,3,3),(2,2,2,2,2)-e_k\big).
```

### Part 4 — Rank-one locus

The minimal presentation matrix of
$\mathrm{Der}(-\log D_{3,5})$ is evaluated on a generic rank-one
matrix

$$
M=uw^T.
$$

Its rank over the fraction field $\mathbb Q(u,w)$ is computed to be $1$.
This calculation is used in the analysis of the number of local generators
on the rank-one locus.

### Part 5 — The ten-plane arrangement

The script considers the arrangement associated with

$$
P_1=e_1,\quad
P_2=e_2,\quad
P_3=e_3,\quad
P_4=(2,3,5),\quad
P_5=(7,-1,4).
$$

It computes the logarithmic derivation module of the ten planes spanned by
pairs of these five vectors and checks its projective dimension.

This provides an independent algebraic check of the non-freeness of the
ten-plane arrangement occurring transversally to $D_{3,5}$.

### Part 6 — A family of five-plane arrangements

The script studies the family

$$
c_1c_2c_3
(c_1+c_2+c_3)
(c_1+s c_2+u c_3).
$$

It computes its logarithmic derivation module and the radical of the Fitting
ideal defining its non-free locus.

### Part 7 — Other matrix sizes

The function

```macaulay2
chartTest
```

computes logarithmic derivation modules in the rank-$(m-1)$ chart for

```text
3x5
4x6
5x7
3x6
```

These calculations provide the computational evidence for the non-freeness
statements for the additional matrix sizes discussed in the paper.

### Part 8 — Local calculations for the 4x6 chart

The presentation matrix for the $4\times6$ chart is evaluated at exact
rational points.

The script compares points with

```text
z = 0
```

corresponding to rank $3$, with points satisfying

```text
z != 0
```

corresponding generically to rank $4$.

For reproducibility, the random seed is fixed by

```macaulay2
setRandomSeed 2026
```

and all evaluations use exact rational arithmetic.

## Reproducibility

The computations use exact arithmetic over `QQ`; no floating-point numerical
approximations are involved.

The source file used for a particular version of the manuscript should be
identified by a Git commit or, preferably, by a tagged GitHub release. This
makes it possible to associate a fixed version of the computational
certificate with a fixed version of the paper.
